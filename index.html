What you'll learn

Foundations

Context is the product

What lives in the context window before you type, why long context rots, and the four levers: Write, Select, Compress, Isolate.

Agents

Engineer the loop

Scratchpads, memories, agentic retrieval vs. RAG, sub-agents, and static context files that keep multi-turn agents coherent.

Debugging

Diagnose failures

Poisoning, Distraction, Confusion, and Clash. Reproduce each one, apply the fix, and compare token costs side by side.

Production

Patterns that ship

Structured outputs, dynamic context injection, tool design, and scheduled headless agents that run unattended.

The five sessions

Session 1

Introduction to Context Engineering

Live Claude Code demos: context rot, lost in the middle, grounding vs. memory, and the 7-rule playbook.

demos/ctx-engineering-principles-claude-code/

Session 2

Engineering Context in Agentic Systems

A hand-rolled agent loop with TF-IDF retrieval. Every context decision is visible. Inspect the raw messages with /context and /stats.

demos/agentic-retrieval/

Session 3

Diagnosing and Fixing Context Failures

Jupyter notebook. Four failure modes, each run broken then fixed, with a token-cost dashboard at the end.

demos/context-failures/

Session 4

Context Engineering Patterns in Modern AI Apps

FastAPI chat app with a 3-layer system prompt, a single create_artifact tool, and an artifact registry that grows back into context.

demos/chat-with-artifacts/

Session 5

Tools and Techniques for Modern Development

Put Claude Code on a cron schedule: daily digests, standup prep, dependency audits, nightly health checks.

demos/ctx-engineering-tools-claude-code/

Run a demo in 30 seconds

# prerequisites: Python 3.12+, uv, an Anthropic API key
curl -LsSf https://astral.sh/uv/install.sh | sh
export ANTHROPIC_API_KEY=sk-ant-...

git clone https://github.com/EnkrateiaLucca/context-engineering-hands-on.git
cd context-engineering-hands-on/demos/agentic-retrieval
uv run app.py

No global installs, no virtualenvs. Each demo declares its own dependencies inline.
